---------------
: Usage Guide :
---------------

This is a step-for-step instruction for how to run this program.

1. Download and install GoLang at https://go.dev/doc/install

2. Use the terminal and navigate from root to main folder

3. Execute the following command: 

```          go run .         ```

4. Open the following URL in your browser:

``` http://localhost:8080/monkeys ```

5. Check your terminal for a fun response
